## 二、GPU vs 无GPU 播放能力对比

### 2.1 播放路数上限

| 配置类型 | GPU 情况 | 最大播放路数 | CPU 占用 | 内存占用 |
|---------|---------|-------------|---------|---------|
| **最低配置** | 无独立 GPU | 4-6 路 | 60-80% | 2-3 GB |
| **最低配置** | 集成 GPU | 6-9 路 | 40-60% | 2-3 GB |
| **推荐配置** | 集成 GPU | 9-12 路 | 30-50% | 3-4 GB |
| **推荐配置** | 独立 GPU | 16 路 | 20-40% | 4-6 GB |
| **高性能配置** | 独立 GPU | 16+ 路 | 15-30% | 4-8 GB |

### 2.2 解码方式对比

| 解码方式 | GPU 支持 | CPU 占用 | 内存占用 | Win7 兼容 | 推荐 |
|---------|---------|---------|---------|----------|------|
| **MSE 硬解** | ✅ 支持 | < 10% | 30-50MB/路 | ✅ IE11+ | ⭐⭐⭐⭐⭐ |
| **WebGL 软解** | ❌ 不依赖 | 40-60% | 100-200MB/路 | ⚠️ 部分支持 | ⭐⭐⭐ |
| **Canvas 软解** | ❌ 不依赖 | 60-80% | 150-300MB/路 | ✅ 支持 | ⭐⭐ |

**结论**: 本项目采用 **MSE 硬解**，GPU 播放能力是软解的 **3-5倍**。

### 2.3 GPU 要求详解

#### 集成显卡（核显）

| 厂商 | 型号要求 | 播放能力 | 说明 |
|------|---------|---------|------|

| **AMD** | Vega 8 及以上 | 9-12 路 | Win10+ 支持 |
| **其他** | OpenGL 3.0+ | 6-9 路 | 兼容性一般 |

#### 独立显卡（独显）

| **GPU** | 无法硬解，黑屏 | 更新显卡驱动或更换显卡 |

## 七、故障排查

### 7.1 播放失败

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| "Play start failed" | 设备离线或网络不通 | 检查设备状态和网络 |
| "No playable URL" | 返回数据缺失 | 检查 WVP 配置 |
| "WebSocket connection failed" | ws-flv 无法连接 | 使用 http-flv 或 hls |
| 黑屏无画面 | GPU 不支持 MSE | 更新显卡驱动 |

### 7.2 性能问题

| 问题 | 表现 | 解决方案 |
|------|------|---------|
| CPU 占用过高 | > 80%，卡顿 | 启用 GPU 硬解 |
| 内存持续增长 | 泄漏 | 重启应用 |
| 首帧慢 | > 3 秒 | 检查网络或降低分辨率 |
| 频繁重连 | 断流 | 检查网络或 WVP 配置 |

## 十、FAQ

**Q1: Win7 能播放吗？**

A: 可以。Win7 SP1 + IE11 或 Chrome 支持 MSE 硬解。建议使用 Chrome。

**Q2: 没有 GPU 能播放吗？**

A: 可以。集成显卡（核显）支持 MSE 硬解，可播放 6-9 路。无 GPU（软解）仅支持 4-6 路。

**Q3: 播放 16 路需要什么配置？**

A: 
- CPU: i5 六核及以上
- 内存: 8 GB 及以上
- GPU: GTX 1050 及以上（或核显 Vega 8）
- 网络: 千兆局域网

**Q4: 如何判断 GPU 是否支持？**

A: 
```
Chrome 地址栏输入: chrome://gpu
查看 "Video Decode" 是否为 "Hardware accelerated"
```

**Q5: 播放时黑屏怎么办？**

A: 
1. 检查显卡驱动是否最新
2. 确认 GPU 支持 MSE（Chrome://gpu）
3. 尝试使用 http-flv 或 hls 协议
4. 降低播放路数
