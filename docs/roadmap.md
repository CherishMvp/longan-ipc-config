# 项目开发规划 Roadmap

## 第一阶段：核心重构与基础稳固 (已完成)
- [x] **架构迁移**：Vue 3 + Vite + Electron + Pinia + TypeScript
- [x] **UI/UX 升级**：迁移至 Shadcn-Vue + Tailwind CSS v4，实现现代化 Dashboard 风格
- [x] **基础功能**：设备增删改查、批量配置、日志系统
- [x] **环境修复**：解决 npm/corepack 环境问题，确保组件库可维护

## 第二阶段：Electron 原生体验增强 (进行中/待启动)
目标：摆脱"网页套壳"感，提供真正的桌面应用体验。

### 1. 系统集成
- **系统托盘 (System Tray)**
  - 支持应用最小化到托盘
  - 托盘图标右键菜单（显示在线设备数、快速退出）
  - 闪烁提醒（当有错误发生时）

- **原生通知系统**
  - 批量操作完成时发送系统通知
  - 设备掉线/连接失败报警

- **应用自动更新**
  - 集成 `electron-updater`
  - 支持差分更新
  - 界面显示更新进度条

### 2. 高级功能开发
- **局域网设备自动发现** (Killer Feature)
  - 实现 UDP 广播或 mDNS 扫描
  - 自动列出局域网内所有可用的 IPC 设备，一键添加

- **本地文件系统直连**
  - 废弃浏览器式的"上传/下载"文件
  - 使用 Electron `fs` 模块直接读写本地 JSON/CSV 配置文件
  - 支持拖拽文件到窗口直接导入

- **多窗口支持**
  - 允许双击设备弹出独立的监控/配置子窗口
  - 窗口间状态同步（Pinia 跨窗口同步）

## 第三阶段：工程化与质量保证
- **自动化构建与发布**
  - 配置 GitHub Actions
  - 自动构建 Windows/macOS/Linux 安装包
  - 发布到 GitHub Releases

- **测试体系**
  - 引入 Vitest 进行单元测试（重点测试协议解析逻辑）
  - 引入 Playwright 进行 E2E 测试

## UI/UX 一致性规范
- **组件库**：严格遵循 shadcn-vue 标准，禁止引入其他 UI 库。
- **主题**：保持 Zinc 风格，严格适配 Dark/Light 模式。
- **图标**：统一使用 Lucide-Vue 图标集。
- **交互**：所有耗时操作必须有 Loading 状态，所有危险操作（删除、批量设置）必须有二次确认。
